Green Mounts Ventures

PHP · MySQL · React Native · REST APIs · Razorpay · CCAvenue · Shiprocket

Built the company's e-commerce website end-to-end in PHP/MySQL and a companion React Native mobile app sharing the same backend — catalog, cart, checkout, coupons, wishlist, reviews and order tracking.

🎯 Problem

Company needed a web storefront and a matching mobile app, both hitting the same live data — with real payments, real shipping, and no separate backend for each.

🛠 Approach

Designed 12+ REST API modules (auth, orders, products, wallet, wishlist, coupons, referrals, subscriptions) consumed by both clients, plus Razorpay/CCAvenue payments and the Shiprocket API.

✅ Result

One backend, two live clients, automated PDF invoicing over cron + PHPMailer — running in production since Jul 2025, source-controlled end-to-end.
